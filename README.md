# 📚 Estudo de Display — HTML & CSS

Projeto criado para estudar e praticar os diferentes valores da propriedade `display` do CSS, entendendo como cada um altera o comportamento, posicionamento e organização dos elementos na página.

## 🎯 Objetivo

Explorar, de forma prática, os principais tipos de `display` e seus casos de uso, observando como os elementos se comportam em diferentes situações.

## 🧩 Displays estudados

| Display | Descrição |
|---|---|
| `block` | Ocupa toda a largura disponível e inicia uma nova linha. |
| `inline` | Ocupa apenas o espaço necessário e permanece na mesma linha. |
| `inline-block` | Combina características de `inline` e `block`. |
| `flex` | Facilita a criação de layouts unidimensionais, organizando elementos em linhas ou colunas. |
| `grid` | Permite criar layouts bidimensionais usando linhas e colunas. |
| `none` | Remove o elemento do fluxo da página. |
